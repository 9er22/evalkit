## 输入

```
如果 file_path 需要以斜杠开头（比如 /home/johndoe/myfile.txt），URL 应该怎么写？
```

## 期望

- 写成 `/files//home/johndoe/myfile.txt`
- 即在 `files` 和 `home` 之间用**两个斜杠**

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `/files//home`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `/files//home/johndoe/myfile.txt`

## 我为什么关心这个 case

反直觉的细节。专门用来测它会不会"想当然"地给一个看起来更正面的答案（比如 URL 编码或单斜杠）。
