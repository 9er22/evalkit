## 输入

```
我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？
```

## 期望

- 用 Starlette 的 path convertor：`/files/{file_path:path}`
- 说明参数名是 `file_path`，末尾的 `:path` 表示匹配任意路径
- 提到 OpenAPI 本身不支持声明"参数内含路径"（会导致难以测试和定义），但 FastAPI 仍然可以做到
- 补充：文档不会额外标注这个参数应当包含路径

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `\{file_path:path\}`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `/files/{file_path:path}`

## 我为什么关心这个 case

`:path` 这个语法很特别，模型容易记成别的形式（如 `{file_path:*}` 或 `{file_path:.+}`）。
