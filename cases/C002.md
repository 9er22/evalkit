## 输入

```
把 item_id 声明成 int 之后，访问 /items/3 时，函数里拿到的到底是字符串 "3" 还是数字 3？为什么会这样？
```

## 期望

- 明确回答：拿到的是 Python int 的 `3`，不是字符串 `"3"`
- 说明这是 FastAPI 提供的自动 request parsing（数据转换）
- 提到返回结果会是 `{"item_id":3}`（没有引号）
- 可以顺带提到同一个类型声明也带来了数据校验

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `"item_id": ?3`（有引号即为错）
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `{"item_id":3}`

## 我为什么关心这个 case

"转换"这个概念很容易被答成"拿到的是字符串"。这题测的是概念有没有被准确传达，而不只是抄对代码。
