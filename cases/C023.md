## 输入

```
文档推荐用 response_model_include / response_model_exclude 来隐藏字段吗？
```

## 期望

- **不推荐**作为首选做法
- 推荐的是用**多个类（继承）**的方式
- 原因：即使使用了这两个参数，OpenAPI / 自动文档里的 JSON Schema **仍然是完整模型的**
- 同时要说清它们确实能用：接受 `set` of `str`；误写成 `list` 或 `tuple` 也会被自动转成 `set`
- 同样适用于 `response_model_by_alias`

## 判定方式

- [ ] 自动判定（关键词 / 正则 / 结构检查）：本 case 不适用
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `it is still recommended to use the ideas above`

## 我为什么关心这个 case

要传达"能用但不推荐"的微妙立场。最容易被答成一个简单的"可以，用 xxx"。
