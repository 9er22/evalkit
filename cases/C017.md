## 输入

```
输入模型里含有明文 password，怎么保证响应里不把它返回给客户端？
```

## 期望

- 另建一个**不含 password** 的输出模型（如 `UserOut`）
- 用 `response_model=UserOut` 声明
- FastAPI 会过滤掉输出模型中未声明的所有数据
- 说明为什么这里要用 `response_model` 参数而不是返回类型注解：两个模型是不同类，编辑器/mypy 会报错
- 可以提到：文档警告过，永远不要存储或返回用户的明文密码

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `UserOut` 且存在 `response_model=`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用
