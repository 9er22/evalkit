## 输入

## 期望

- 从 `pydantic` 导入 `BaseModel`，声明一个继承它的类
- 用标准 Python 类型声明属性
- **有默认值的不是必填，否则必填**；用 `None` 表示可选
- 例子里 `name` 和 `price` 必填，`description` 和 `tax` 可选
- 把它声明为路径操作函数的参数：`async def create_item(item: Item)`
- 可以补充 FastAPI 会做：读 JSON、转换类型、校验、生成 JSON Schema
