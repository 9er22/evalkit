## 输入

```
想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。
```

## 期望

- 用 Python 标准库的 `Enum`
- 定义时**同时继承 `str` 和 `Enum`**：`class ModelName(str, Enum):`
- 说明继承 `str` 的作用：让 API 文档知道这些值是 string 类型，才能正确渲染
- 类属性写成固定值（如 `alexnet = "alexnet"`）
- 然后把路径参数的类型注解写成这个 Enum 类

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `class\s+\w+\(str,\s*Enum\)`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、格式遵循
- [ ] 人工判定：本 case 不适用

## 语料依据

- `class ModelName(str, Enum):`

## 我为什么关心这个 case

"为什么要继承 str"是这份文档独有的点，也是极易被省略的一句。
