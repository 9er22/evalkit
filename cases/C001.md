## 输入

```
根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。
```

## 期望

- 用与 Python format string 相同的语法声明路径：`/items/{item_id}`
- 函数参数名必须和路径参数名一致（都是 `item_id`）
- 给出完整代码：`from fastapi import FastAPI`、`app = FastAPI()`、`@app.get("/items/{item_id}")`、返回 `{"item_id": item_id}`
- 提到访问 `/items/foo` 会得到 `{"item_id":"foo"}`
- 不出现语料中不存在的 API

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `/items/\{item_id\}`；检查存在代码块
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、格式遵循
- [ ] 人工判定：本 case 不适用
