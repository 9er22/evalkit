## 输入

```
我的路径操作函数直接返回一个数据库对象（不是 Pydantic 类型），会发生什么？怎么解决？
```

## 期望

- FastAPI 会尝试从返回类型注解创建 Pydantic 响应模型，然后**失败**
- 如果返回类型注解是 `Response` 与 `dict` 的**联合（union）**，同样会失败
- 解法：设置 `response_model=None` 禁用响应模型生成
- 补充：如果注解是单个 `Response` 类或其子类（`RedirectResponse`、`JSONResponse` 等），FastAPI 能自动处理
- 可以提到：想保留类型注解给编辑器看，又不想 FastAPI 生成响应模型，就用 `response_model=None`

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `response_model=None`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `response_model=None`

"部分覆盖 + 有解"的题。测它能不能既承认限制、又给出文档里的解法，而不是二选一。
