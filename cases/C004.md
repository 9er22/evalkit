## 输入

```
同时有 /users/me 和 /users/{user_id} 两个路径操作，声明顺序应该怎么排？写反了会发生什么？
```

## 期望

- `/users/me` 必须声明在 `/users/{user_id}` **之前**
- 原因：路径操作是按顺序匹配（evaluated in order）的
- 写反的后果：`/users/me` 会被 `/users/{user_id}` 匹配掉，FastAPI 会认为收到了 `user_id="me"`
- 可以补充：同一个路径不能被重复定义，先声明的那个永远生效

## 判定方式

- [ ] 自动判定（关键词 / 正则 / 结构检查）：本 case 不适用
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `evaluated in order`

## 我为什么关心这个 case

这题必须讲因果。只说"顺序很重要"等于没答——文档里明确写了为什么。
