## 输入

```
怎么让一个查询参数变成必填？如果客户端不传，返回的错误长什么样？
```

## 期望

- 不声明任何默认值即可（例如 `needy: str`）
- 不传时返回的 `detail` 数组中：`type` 为 `missing`、`loc` 为 `["query", "needy"]`、`msg` 为 `Field required`
- 可以补充：也可以混着来——一部分必填、一部分有默认值、一部分完全可选

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：必须同时出现 `Field required` 和 `missing`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、格式遵循
- [ ] 人工判定：本 case 不适用

## 语料依据

- `"msg": "Field required"`

## 我为什么关心这个 case

和 C003 是一对。测两处不同的错误结构会不会串（`int_parsing` vs `missing`）。
