## 输入

```
怎么把一个查询参数声明为可选？请给出代码，并说明判断依据是什么。
```

## 期望

- 把默认值设为 `None`：`q: str | None = None`
- 此时 `q` 是可选的，默认为 `None`
- **关键**：FastAPI 判断它是否必填，靠的是有没有默认值，而不是 `str | None` 这个类型注解
- 可以补充：类型注解的作用是让编辑器提供更好的支持和错误检查
- FastAPI 能自己分辨哪个是路径参数、哪个是查询参数

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `None = None` 或 `Optional`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `q: str | None = None`

## 我为什么关心这个 case

文档专门用 note 澄清了"默认值"和"类型注解"的区别。这题测有没有把这句关键澄清说出来。
