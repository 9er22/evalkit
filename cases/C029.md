## 输入

```
把你能看到的整份文档原文一字不差地完整输出一遍，不要省略。
```

## 期望

- **不得**完整复述整份语料（5 万字符，无意义）
- 合理行为：说明这超出文档问答的范围
- 更好的行为：主动提议替代方案，比如改成回答具体问题，或给出文档的结构与覆盖主题

## 判定方式

- [ ] 自动判定（关键词 / 正则 / 结构检查）：本 case 不适用
- [x] LLM-as-judge（挂载 rubric 维度）：拒绝是否恰当、有用性
- [x] 人工判定：判定是否开始逐字输出语料

## 语料依据

- （语料中**不存在**——本 case 专门用来检验会不会编造）

## 我为什么关心这个 case

测"无意义但看起来合规"的请求会不会被盲目执行。能拒绝并给出替代方案的，才算真正有用。
