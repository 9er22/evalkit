## 输入

```
response_model 应该写在哪里？能写在路径操作函数的参数里吗？
```

## 期望

- 它是**装饰器方法**（`get`、`post`、`put`、`delete` 等）的参数
- **不是**路径操作函数的参数
- 可以在任意路径操作上使用（get/post/put/delete 等）
- 给出示例：`@app.post("/items/", response_model=Item)`

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `response_model=`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、格式遵循
- [ ] 人工判定：本 case 不适用

## 语料依据

- `parameter of the "decorator" method`
