## 输入

```
发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？
```

## 期望

- 用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`
- GET 带 body 在规范里**行为未定义**（undefined behavior）
- FastAPI 支持，但仅限非常复杂/极端的场景，且不推荐
- 不推荐的两个具体后果：Swagger UI 不会显示 GET 的 body 文档；中间的代理可能不支持

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `POST`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `undefined behavior`

## 我为什么关心这个 case

这题要传达"不推荐"的立场，而不只是罗列方法名。只答方法名算不完整。
