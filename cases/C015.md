## 输入

```
同一个路径操作里同时有请求体、路径参数和查询参数，FastAPI 怎么区分它们？
```

## 期望

- 参数也在 **path** 中声明了的 → 路径参数
- 参数是**单一类型**（`int`、`float`、`str`、`bool` 等）→ 查询参数
- 参数声明为 **Pydantic model** 类型 → 请求体
- 声明顺序不重要，按名字和类型识别

## 判定方式

- [ ] 自动判定（关键词 / 正则 / 结构检查）：本 case 不适用
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `it will be interpreted as a **query** parameter`

## 我为什么关心这个 case
