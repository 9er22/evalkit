## 输入

```
response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？
```

## 期望

- 让**有默认值但实际未被设置**的字段不出现在响应里
- 请求 `foo` 返回 `{"name": "Foo", "price": 50.2}`
- **关键细节**：如果数据里显式设置了与默认值相同的值（如 `baz` 的 `tax=10.5`），该字段**仍会**包含在响应中
- 可以补充同类参数：`response_model_exclude_defaults`、`response_model_exclude_none`

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：正则 `"price": ?50.2`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性、有用性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `response_model_exclude_unset=True`

## 我为什么关心这个 case

"同值但显式设置仍保留"这个细节最容易被漏掉，而它正是这个参数最容易踩的坑。
