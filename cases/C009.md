## 输入

```
文档例子里的 skip 和 limit 两个查询参数，默认值分别是多少？如果只访问 /items/ 不传任何参数，会发生什么？
```

## 期望

- `skip=0`，`limit=10`
- 只访问 `/items/` 等同于访问 `/items/?skip=0&limit=10`
- 如果访问 `/items/?skip=20`，则 `skip=20`、`limit` 仍为默认值 `10`
- 可以说明：查询参数不是路径的固定部分，所以可以可选、可以有默认值

## 判定方式

- [ ] 自动判定（关键词 / 正则 / 结构检查）：本 case 不适用
- [x] LLM-as-judge（挂载 rubric 维度）：事实性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `skip: int = 0, limit: int = 10`

## 我为什么关心这个 case

最简单的查证题。测它会不会把默认值说反，或者编造一个文档里没有的数字。
