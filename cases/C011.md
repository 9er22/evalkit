## 输入

```
查询参数声明为 bool 类型时，URL 里写哪些值会被当成 True？请尽量列全。
```

## 期望

- `1`
- `True`
- `true`
- `on`
- `yes`
- 以及上述任意大小写变体（全大写、首字母大写等）
- 其他情况为 `False`

## 判定方式

- [x] 自动判定（关键词 / 正则 / 结构检查）：必须同时出现 `on` 和 `yes`
- [x] LLM-as-judge（挂载 rubric 维度）：事实性
- [ ] 人工判定：本 case 不适用

## 语料依据

- `short=yes`

## 我为什么关心这个 case

五种写法里，`on` 和 `yes` 最容易被漏掉。这题测完整性。
