# EvalKit

一个最小的 LLM / Agent 输出评测工具。

给任意一个 LLM / Agent 应用做批量评测：喂一批测试 case，得到**通过率、失败分类、版本间回归对比**。

这个仓库的重点不是代码，是**评分标准（rubric）怎么定**——以及定完之后发现了什么问题。

---

## 它在解决什么

做 AI 应用的人几乎都在做 Agent，很少有人做 Eval。但一个 Agent 上线之后必然要回答的问题只有三个：

1. 它现在到底好不好？
2. 改了一版之后，是变好了还是变坏了？
3. 坏在哪一类问题上？

这三个问题没有 eval 就只能靠感觉回答。EvalKit 就是把"感觉"变成"可复现的数字"。
