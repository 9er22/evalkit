# 环境配置

两件需要本人操作的事：**GitHub 远程**、**DeepSeek API key**。
其余都能脚本化，不需要你动手。

## 第 1 部分｜GitHub 远程仓库

已定方案：**GitHub · 仓库名 `evalkit` · 私有 · 用 gh CLI 认证**。

### 1.1 装 gh

在 **PowerShell 或 CMD**（不是 Git Bash）里执行：

```powershell
winget install --id GitHub.cli
```

装完**必须重开一个终端**，否则 `gh` 命令找不到。
验证：

```bash
gh --version
```

### 1.2 登录

```bash
gh auth login
```

交互式问答按这个顺序选：

| 提问 | 选 |
|---|---|
| What account do you want to log into? | `GitHub.com` |
| What is your preferred protocol for Git operations? | `HTTPS` |
| Authenticate Git with your GitHub credentials? | `Yes` |
| How would you like to authenticate GitHub CLI? | `Login with a web browser` |

然后终端会给你**一个 8 位验证码**（形如 `ABCD-1234`），复制它，回车，浏览器会自动打开，粘贴、授权。

### 1.3 建仓库并推送

```bash
cd /d/vibecoding/evalkit
git branch -M main
gh repo create evalkit --private --source=. --push
```

`git branch -M main` 这行是把本地的 `master` 改成 `main`——GitHub 默认分支是 `main`，不改也能推，但推完默认分支会是 `master`，看着别扭。

验证：

```bash
git remote -v          # 应该看到 origin 指向 git@/https 的 github.com
gh repo view --web     # 浏览器打开仓库页
```

### 1.4 一个必须处理的坑：提交身份

你现在的全局 git 身份是：

```

```

**这个邮箱是 Gitee 的。** 推到 GitHub 后，这 4 个 commit 不会关联到你的 GitHub 账号——贡献图不绿，点进 commit 看不到头像。

查你 GitHub 的 noreply 邮箱：

```bash
gh api user --jq '"\(.id)+\(.login)@users.noreply.github.com"'
```

会输出形如 `12345678+yourname@users.noreply.github.com`，然后：

```bash
git config --global user.email "上面输出的那串"
git config --global user.name "郑常硕"
```

## 第 2 部分｜DeepSeek API key

### 2.1 填 key

```bash
cd /d/vibecoding/evalkit
cp .env.example .env
```

然后用编辑器打开 `.env`，把 `sk-xxx` 换成真实 key：

```
DEEPSEEK_API_KEY=sk-你的真实key
```

`.env` 已经在 `.gitignore` 里（第 9、10 行 `.env` 和 `.env.*`），**不会被提交**。提交前习惯性确认一次：

```bash
git status --short     # 不应该出现 .env
git check-ignore .env  # 输出 .env 说明已被忽略
```

### 2.2 验证链路


## 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `gh: command not found` | 终端没重开。winget 装完必须新开一个 |
| `gh auth login` 卡在浏览器 | 复制验证码那步超时了，重跑一次 |
| `gh repo create` 说仓库已存在 | 网页上已经建过 `evalkit` 了，改用 `gh repo set-default` 或直接 `git remote add origin https://github.com/你的用户名/evalkit.git` |
| 推送报 403 | PAT 没勾 `repo` 权限，或 `gh auth refresh -s repo` |
| runner 报 401 / 402 | key 错了，或账户余额不足 |
| runner 报 `DEEPSEEK_API_KEY not found` | `.env` 没建，或建在了别的目录 |
