# C003（normal）

**问** 如果路径参数声明为 int，访问 /items/foo 会返回什么错误？请把完整的 JSON 错误结构写出来。

**答**

根据文档，如果路径参数 `item_id` 声明为 `int`，访问 `/items/foo` 会返回一个 HTTP 错误，完整的 JSON 错误结构如下：

```JSON
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": [
        "path",
        "item_id"
      ],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}
```

依据是文档中 "Data validation" 一节的说明：因为路径参数 `item_id` 的值为 `"foo"`，它不是 `int` 类型，所以会返回上述错误。
