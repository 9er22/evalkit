# C013（normal）

**问** 要接收一个 JSON 请求体，文档里怎么做？请给出完整代码，并说明哪些字段是必填。

**答**

根据文档，要接收一个 JSON 请求体，你需要使用 Pydantic 的 `BaseModel` 来定义一个数据模型，然后在路径操作函数中将其声明为参数。

完整代码示例（来自文档）：

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```

**必填字段说明：**

- `name`：必填，类型为 `str`，因为它没有默认值。
- `price`：必填，类型为 `float`，因为它没有默认值。

**可选字段说明：**

- `description`：可选，类型为 `str | None`，默认值为 `None`。
- `tax`：可选，类型为 `float | None`，默认值为 `None`。

文档明确指出："当模型属性有默认值时，它不是必填的。否则，它是必填的。使用 `None` 使其仅为可选。"
