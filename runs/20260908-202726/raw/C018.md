# C018（normal）

**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

根据文档，`response_model_exclude_unset=True` 是 *path operation decorator* 的一个参数，作用是：**只返回实际被设置过的字段，不包含那些使用了默认值的字段**。

文档中给出的例子是：

```python
@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

其中 `Item` 模型有默认值字段（如 `description` 默认为 `None`、`tax` 默认为 `10.5`、`tags` 默认为空列表 `[]`）。

对于 id 为 `foo` 的 item，其存储数据为：

```python
{"name": "Foo", "price": 50.2}
```

因为 `foo` 的数据中只显式设置了 `name` 和 `price`，没有设置其他字段，所以响应中不会包含那些默认值字段。文档明确说明响应会是：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```
