# C004（normal）

**问** 同时有 /users/me 和 /users/{user_id} 两个路径操作，声明顺序应该怎么排？写反了会发生什么？

**答**

根据文档，`/users/me` 必须声明在 `/users/{user_id}` **之前**。

文档中明确说明：

> Because *path operations* are evaluated in order, you need to make sure that the path for `/users/me` is declared before the one for `/users/{user_id}`

如果写反了（即先声明 `/users/{user_id}`），文档指出：

> Otherwise, the path for `/users/{user_id}` would match also for `/users/me`, "thinking" that it's receiving a parameter `user_id` with a value of `"me"`.

也就是说，请求 `/users/me` 会被 `/users/{user_id}` 捕获，`user_id` 参数会被赋值为字符串 `"me"`，而不是进入 `/users/me` 对应的处理函数。
