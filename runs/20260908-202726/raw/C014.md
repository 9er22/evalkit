# C014（normal）

**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档，发送请求体应该使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH` 方法。

文档明确指出，使用 `GET` 请求发送请求体在规范中具有未定义的行为。虽然 FastAPI 出于非常复杂/极端用例的考虑支持这种方式，但这是不鼓励的。具体后果包括：

1. 使用 Swagger UI 的交互式文档在 `GET` 请求时不会显示请求体的文档。
2. 中间的代理服务器可能不支持这种用法。
