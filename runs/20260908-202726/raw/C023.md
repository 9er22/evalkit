# C023（edge）

**问** 文档推荐用 response_model_include / response_model_exclude 来隐藏字段吗？

**答**

文档**不推荐**用 `response_model_include` / `response_model_exclude` 来隐藏字段。

文档在“Response Model - Return Type”章节中明确说明：

> 但更推荐使用上面提到的思路，即使用多个类，而不是这些参数。

原因是：即使你使用 `response_model_include` 或 `response_model_exclude` 来省略某些属性，应用 OpenAPI（以及文档）中生成的 JSON Schema 仍然是完整模型的。`response_model_by_alias` 也有同样的问题。

文档推荐的做法是：定义不同的输入/输出模型（例如 `UserIn` 和 `UserOut`），通过 `response_model` 参数或返回类型注解来过滤数据，这样既能保证数据安全，也能让文档和 JSON Schema 正确反映实际返回的数据结构。
