# C017（normal）

**问** 输入模型里含有明文 password，怎么保证响应里不把它返回给客户端？

**答**

根据文档，你可以通过**定义单独的输入模型和输出模型**来保证响应中不返回明文 `password`。

具体做法是：

1. 创建一个包含 `password` 字段的输入模型（如 `UserIn`）。
2. 创建一个不包含 `password` 字段的输出模型（如 `UserOut`）。
3. 在 *path operation* 装饰器中使用 `response_model=UserOut` 参数。

文档中的示例代码如下：

```python
from typing import Any

from fastapi import FastAPI
from pydantic import BaseModel, EmailStr

app = FastAPI()


class UserIn(BaseModel):
    username: str
    password: str
    email: EmailStr
    full_name: str | None = None


class UserOut(BaseModel):
    username: str
    email: EmailStr
    full_name: str | None = None


@app.post("/user/", response_model=UserOut)
async def create_user(user: UserIn) -> Any:
    return user
```

文档说明：即使 *path operation function* 返回的是包含密码的 `UserIn` 对象，由于声明了 `response_model=UserOut`，**FastAPI** 会使用 Pydantic 自动过滤掉所有未在输出模型中声明的数据（即 `password` 字段），从而保证响应中不会包含明文密码。

文档还特别警告：**永远不要**像下面这样将明文密码存储在响应中，除非你完全了解所有风险：

```python
# Don't do this in production!
@app.post("/user/")
async def create_user(user: UserIn) -> UserIn:
    return user
```
