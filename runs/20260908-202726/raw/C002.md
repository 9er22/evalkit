# C002（normal）

**问** 把 item_id 声明成 int 之后，访问 /items/3 时，函数里拿到的到底是字符串 "3" 还是数字 3？为什么会这样？

**答**

根据文档，访问 `/items/3` 时，函数里拿到的会是数字 `3`（Python `int`），而不是字符串 `"3"`。

文档在“Data conversion”一节中明确说明：

> Notice that the value your function received (and returned) is `3`, as a Python `int`, not a string `"3"`.

原因是，当你将路径参数 `item_id` 声明为 `int` 类型后，**FastAPI** 会自动对请求数据进行“解析”（parsing），即将来自 HTTP 请求的字符串转换为 Python 数据类型。文档中提到：

> So, with that type declaration, **FastAPI** gives you automatic request "parsing".

因此，类型声明不仅提供了编辑器支持和数据验证，还负责将 URL 中的字符串参数自动转换为你在函数签名中声明的 Python 类型。
