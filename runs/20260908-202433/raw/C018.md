# C018（normal）

**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

## `response_model_exclude_unset=True` 的作用

根据文档（`docs/en/docs/tutorial/response-model.md`），`response_model_exclude_unset=True` 是 *path operation decorator* 的一个参数，用来**排除那些没有被显式设置（unset）的字段**，即不把默认值包含在响应中。

文档中的说明：

> You can set the *path operation decorator* parameter `response_model_exclude_unset=True` ... and those default values won't be included in the response, only the values actually set.

也就是说，只有实际被设置过的值才会出现在响应里，那些只是取了默认值的字段会被省略。

## 请求 id 为 `foo` 的 item 会返回什么

文档中的示例模型和 `items` 数据如下：

```python
class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float = 10.5
    tags: list[str] = []


items = {
    "foo": {"name": "Foo", "price": 50.2},
    ...
}


@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

对于 id 为 `foo` 的 item，原始数据只设置了 `name` 和 `price`，其余字段（`description`、`tax`、`tags`）都取默认值。因此使用 `response_model_exclude_unset=True` 后，响应（不包含默认值）为：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```

文档原文：

> So, if you send a request to that *path operation* for the item with ID `foo`, the response (not including default values) will be:
>
> ```JSON
> {
>     "name": "Foo",
>     "price": 50.2
> }
> ```

## 补充说明

文档还提到，如果数据中**显式设置**了某个字段（即使它的值恰好等于默认值），该字段仍会被包含在响应中。例如 id 为 `baz` 的 item，虽然 `description`、`tax`、`tags` 的值与默认值相同，但因为它们是显式设置的，所以会被包含。

此外，文档还提到可以使用 `response_model_exclude_defaults=True` 和 `response_model_exclude_none=True` 这两个参数。
