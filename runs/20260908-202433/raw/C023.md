# C023（edge）

**问** 文档推荐用 response_model_include / response_model_exclude 来隐藏字段吗？

**答**

不推荐。

文档在 `response_model_include` 和 `response_model_exclude` 一节里明确给出了 tip：

> But it is still recommended to use the ideas above, using multiple classes, instead of these parameters.

也就是说，文档建议改用上面讲过的**多个类（继承）**的方式，而不是用这两个参数。

原因是：

> This is because the JSON Schema generated in your app's OpenAPI (and the docs) will still be the one for the complete model, even if you use `response_model_include` or `response_model_exclude` to omit some attributes.

即使用这两个参数省略了某些属性，OpenAPI（以及文档）里生成的 JSON Schema 仍然是完整模型的 schema。文档还提到 `response_model_by_alias` 也有同样的问题。

文档把这两个参数定位为一种"快捷方式"（quick shortcut），仅适用于"你只有一个 Pydantic 模型、又想从输出里去掉一些数据"的场景。
