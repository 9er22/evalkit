# C010（normal）

**问** 怎么把一个查询参数声明为可选？请给出代码，并说明判断依据是什么。

**答**

根据文档，把查询参数声明为可选的方式是**给它设置默认值 `None`**。

## 代码示例

文档中 `docs_src/query_params/tutorial002_py310.py` 的例子：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

在这个例子中，函数参数 `q` 就是可选的，默认值为 `None`。

## 判断依据

文档中明确说明了以下几点：

1. **Optional parameters 一节**指出：
   > "The same way, you can declare optional query parameters, by setting their default to `None`"
   > （同样地，你可以通过把默认值设为 `None` 来声明可选的查询参数。）

   > "In this case, the function parameter `q` will be optional, and will be `None` by default."
   > （在这种情况下，函数参数 `q` 将是可选的，默认值为 `None`。）

2. **Required query parameters 一节**进一步说明：
   > "When you declare a default value for non-path parameters (for now, we have only seen query parameters), then it is not required."
   > （当你为非路径参数声明了默认值时，它就不是必需的。）

   > "If you don't want to add a specific value but just make it optional, set the default as `None`."
   > （如果你不想指定具体值，只是想让它可选，就把默认值设为 `None`。）

3. **Request Body 文档中的 note** 也补充了 FastAPI 判断"非必需"的机制：
   > "FastAPI will know that the value of `q` is not required because of the default value `= None`."
   > "The `str | None` is not used by FastAPI to determine that the value is not required, it will know it's not required because it has a default value of `= None`."

   也就是说，**FastAPI 判断参数是否必需，依据的是"有没有默认值"，而不是类型注解里的 `| None`**。类型注解 `str | None` 只是为了让编辑器提供更好的类型支持。

## 小结

- 声明可选查询参数：设置默认值 `= None`。
- 判断依据：**有默认值 → 非必需（可选）；没有默认值 → 必需**。
