# C015（normal）

**问** 同一个路径操作里同时有请求体、路径参数和查询参数，FastAPI 怎么区分它们？

**答**

根据文档，FastAPI 通过函数参数的**声明方式**来区分它们。文档在 "Request body + path + query parameters" 一节中明确给出了识别规则：

- 如果参数**同时声明在路径中**（即出现在 `@app.put("/items/{item_id}")` 这类路径里），它会被当作**路径参数**。
- 如果参数是**单一类型**（如 `int`、`float`、`str`、`bool` 等），它会被解释为**查询参数**。
- 如果参数被声明为 **Pydantic 模型**类型，它会被解释为请求**体**（body）。

文档给出的示例：

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
```

在这个例子里：
- `item_id` 出现在路径 `/items/{item_id}` 中，所以是路径参数；
- `item` 是 Pydantic 模型 `Item`，所以从请求体读取；
- `q` 是单一类型 `str`，所以是查询参数。

文档还特别说明：`q` 之所以是可选的，是因为它有默认值 `= None`，而不是因为 `str | None` 这个类型标注（类型标注只是为了让编辑器提供更好的支持）。

另外，文档在 "Multiple path and query parameters" 一节也提到，多个路径参数和查询参数可以同时声明，FastAPI 知道哪个是哪个，**不需要按特定顺序声明**，它们会按名称被识别。
