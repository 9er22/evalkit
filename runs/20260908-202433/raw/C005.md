# C005（normal）

**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

文档推荐使用标准的 Python `Enum`（枚举）来实现这个需求。

具体做法是：导入 `Enum`，然后创建一个同时继承自 `str` 和 `Enum` 的子类。继承 `str` 可以让 API 文档知道这些值必须是字符串类型，并能正确渲染。然后创建带有固定值的类属性，这些就是可用的合法值。

文档中的 `Enum` 类定义方式如下：

```python
from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

然后在路径操作中，用这个枚举类作为路径参数的类型注解：

```python
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}

    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeCNN all the images"}

    return {"model_name": model_name, "message": "Have some residuals"}
```

依据：文档 "Path Parameters" 章节的 "Predefined values" 部分（`docs/en/docs/tutorial/path-params.md`）。

补充几点文档提到的要点：
- 路径参数的值会是一个**枚举成员**（enumeration member）。
- 可以用 `model_name is ModelName.alexnet` 这样的方式比较枚举成员。
- 可以用 `model_name.value`（或 `ModelName.lenet.value`）获取实际的字符串值。
- 因为可用值是预定义的，交互式文档会很好地展示它们。
