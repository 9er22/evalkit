# C006（normal）

**问** 当路径参数是一个枚举成员时，怎么取出它真正的字符串值？

**答**

根据文档，当路径参数被声明为枚举类型时，函数收到的参数是一个**枚举成员**（enumeration member）。要取出它真正的值（本例中是 `str`），可以使用 `.value` 属性。

文档中的说明：

> You can get the actual value (a `str` in this case) using `model_name.value`, or in general, `your_enum_member.value`

也就是说，用 `model_name.value`，或者更一般地 `your_enum_member.value`。

文档还给出了一个提示：

> You could also access the value `"lenet"` with `ModelName.lenet.value`.

即也可以通过 `ModelName.lenet.value` 直接访问对应值。

示例代码中就是这样用的：

```python
if model_name.value == "lenet":
    return {"model_name": model_name, "message": "LeCNN all the images"}
```

另外，文档提到枚举成员也可以直接返回，FastAPI 会在返回给客户端之前把它们转换成对应的值（这里是字符串）。
