# 接收 JSON 请求体

根据文档，要接收 JSON 请求体，需要用 Pydantic 的 `BaseModel` 定义一个数据模型，然后把它声明为路径操作函数的参数。

## 完整代码

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```

## 哪些字段是必填

文档明确说明：

> The same as when declaring query parameters, when a model attribute has a default value, it is not required. Otherwise, it is required. Use `None` to make it just optional.

也就是说：

- **必填字段**：`name`（`str`）和 `price`（`float`）——它们没有默认值。
- **可选字段**：`description`（默认 `None`）和 `tax`（默认 `None`）——它们有默认值。

因此下面这个 JSON 是有效的（省略了可选字段）：

```JSON
{
    "name": "Foo",
    "price": 45.2
}
```

## 补充说明

- 文档建议发送请求体时使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`。用 `GET` 发送请求体在规范中行为未定义，虽然 FastAPI 支持，但不推荐。
- 声明后，FastAPI 会自动：把请求体读取为 JSON、转换类型、校验数据（无效时返回清晰的错误）、把数据放进参数 `item`，并生成 JSON Schema 用于自动文档。
