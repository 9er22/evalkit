# C009（normal）

**问** 文档例子里的 skip 和 limit 两个查询参数，默认值分别是多少？如果只访问 /items/ 不传任何参数，会发生什么？

**答**

根据文档（`docs/en/docs/tutorial/query-params.md`）：

**默认值：**
- `skip` 的默认值是 `0`
- `limit` 的默认值是 `10`

文档中的示例代码：

```python
@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):
    return fake_items_db[skip : skip + limit]
```

**只访问 `/items/` 不传任何参数时：**

文档明确说明，访问 `http://127.0.0.1:8000/items/` 与访问 `http://127.0.0.1:8000/items/?skip=0&limit=10` 是等价的，也就是说会使用默认值 `skip=0` 和 `limit=10`。

文档原文：

> So, going to the URL:
> ```
> http://127.0.0.1:8000/items/
> ```
> would be the same as going to:
> ```
> http://127.0.0.1:8000/items/?skip=0&limit=10
> ```

因此，不传参数时函数会以 `skip=0`、`limit=10` 执行，返回 `fake_items_db[0:10]`（即列表的前 10 项）。
