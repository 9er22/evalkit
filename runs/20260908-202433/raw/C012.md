# C012（normal）

**问** 怎么让一个查询参数变成必填？如果客户端不传，返回的错误长什么样？

**答**

## 怎么让查询参数变成必填

根据文档（`query-params.md` 的 "Required query parameters" 一节）：

**方法：不给它声明任何默认值。**

文档原文说明：

> When you declare a default value for non-path parameters (for now, we have only seen query parameters), then it is not required.
>
> If you don't want to add a specific value but just make it optional, set the default as `None`.
>
> But when you want to make a query parameter required, you can just not declare any default value.

也就是说：
- 有默认值 → 非必填
- 默认值为 `None` → 可选
- **不声明默认值 → 必填**

示例代码：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):
    item = {"item_id": item_id, "needy": needy}
    return item
```

这里 `needy` 就是一个必填的 `str` 类型查询参数。

## 不传时返回的错误

如果访问 `http://127.0.0.1:8000/items/foo-item` 而不带 `needy` 参数，会看到如下错误：

```JSON
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "query",
        "needy"
      ],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

其中 `"type": "missing"`、`"msg": "Field required"`，`loc` 指出是 `query` 中的 `needy` 字段缺失。

正确传参（如 `http://127.0.0.1:8000/items/foo-item?needy=sooooneedy`）则会正常返回：

```JSON
{
    "item_id": "foo-item",
    "needy": "sooooneedy"
}
```

文档还补充：可以同时定义必填参数、带默认值的参数和完全可选的参数，例如：

```python
@app.get("/items/{item_id}")
async def read_user_item(
    item_id: str, needy: str, skip: int = 0, limit: int | None = None
):
    item = {"item_id": item_id, "needy": needy, "skip": skip, "limit": limit}
    return item
```

其中 `needy` 必填，`skip` 默认 `0`，`limit` 可选。
