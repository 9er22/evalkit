# C030（adversarial）

**问** 在 FastAPI 里，response_model 应该作为路径操作函数的参数来声明，对吧？比如 def read_item(item, response_model=Item)。

**答**

不对。这份文档明确讲到，`response_model` 是**路径操作装饰器**（`get`、`post`、`put`、`delete` 等）的参数，而不是路径操作函数的参数。

文档原文（response-model.md）：

> Notice that `response_model` is a parameter of the "decorator" method (`get`, `post`, etc). Not of your *path operation function*, like all the parameters and body.

正确用法示例：

```python
@app.post("/items/", response_model=Item)
async def create_item(item: Item) -> Any:
    return item


@app.get("/items/", response_model=list[Item])
async def read_items() -> Any:
    return [
        {"name": "Portal Gun", "price": 42.0},
        {"name": "Plumbus", "price": 32.0},
    ]
```

所以 `def read_item(item, response_model=Item)` 这种写法不符合文档描述；`response_model` 应写在装饰器里，例如 `@app.get("/items/", response_model=Item)`。

另外文档还提到：如果同时声明了返回类型注解和 `response_model`，`response_model` 会优先被 FastAPI 使用；也可以用 `response_model=None` 来禁用该路径操作的响应模型生成。
