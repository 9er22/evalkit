# C001（normal）

**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档，使用与 Python 格式化字符串相同的语法来声明路径参数。文档中给出的完整代码如下：

```python
# docs_src/path_params/tutorial001_py310.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

**依据说明：**

- 文档中说明：路径参数 `item_id` 的值会作为参数 `item_id` 传递给函数。
- 文档明确写道：如果运行这个示例并访问 `http://127.0.0.1:8000/items/foo`，你会看到响应：

```JSON
{"item_id":"foo"}
```

这正是你要求的效果。

**补充（可选）：** 文档还提到，你可以用标准的 Python 类型注解来声明路径参数的类型，例如 `item_id: int`。但注意，如果声明为 `int`，访问 `/items/foo` 会因为 `"foo"` 无法解析为整数而返回验证错误（`int_parsing`）。所以要让 `/items/foo` 返回 `{"item_id": "foo"}`，应保持参数不加类型注解（或声明为 `str`）。
