# C014（normal）

**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档（`docs/en/docs/tutorial/body.md`）：

**发送请求体应该用的 HTTP 方法：**

文档说明，要发送数据，应该使用以下方法之一：`POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`。

**如果用 GET 发送请求体会怎样：**

文档指出：

- 在规范中，用 `GET` 请求发送请求体是**未定义行为（undefined behavior）**。
- 不过，FastAPI 仍然支持它，**仅用于非常复杂/极端的用例**。
- 由于这种做法不被推荐，使用 Swagger UI 的交互式文档在 `GET` 请求时**不会显示请求体的文档**。
- 中间经过的代理（proxies）**可能不支持**它。
