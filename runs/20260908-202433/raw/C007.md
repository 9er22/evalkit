# C007（normal）

**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

文档里讲到了这个用法。

**声明方式**：使用 Starlette 的 path convertor，在路径参数名后面加上 `:path`：

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

文档说明的要点：

- 这里参数名是 `file_path`，最后的 `:path` 告诉 FastAPI 该参数应匹配任意 *path*。
- 文档也指出 OpenAPI 本身不支持声明一个路径参数内部包含路径，但 FastAPI 借助 Starlette 的内部工具仍然可以做到；文档依然能正常工作，只是不会额外说明该参数应包含路径。
- 如果参数需要以斜杠开头（例如 `/home/johndoe/myfile.txt`），URL 会变成 `/files//home/johndoe/myfile.txt`，即 `files` 和 `home` 之间是双斜杠 `//`。
