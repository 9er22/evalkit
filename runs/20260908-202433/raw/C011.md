# C011（normal）

**问** 查询参数声明为 bool 类型时，URL 里写哪些值会被当成 True？请尽量列全。

**答**

根据文档（`docs/en/docs/tutorial/query-params.md` 的 "Query parameter type conversion" 一节），当查询参数声明为 `bool` 类型时，以下写法都会被解析为 `True`：

- `?short=1`
- `?short=True`
- `?short=true`
- `?short=on`
- `?short=yes`

文档还说明：**任何其他大小写变体**（例如全大写、首字母大写等）也都会被当作 `True`；否则为 `False`。

原文：

> In this case, if you go to:
> ```
> http://127.0.0.1:8000/items/foo?short=1
> ```
> or
> ```
> http://127.0.0.1:8000/items/foo?short=True
> ```
> or
> ```
> http://127.0.0.1:8000/items/foo?short=true
> ```
> or
> ```
> http://127.0.0.1:8000/items/foo?short=on
> ```
> or
> ```
> http://127.0.0.1:8000/items/foo?short=yes
> ```
> or any other case variation (uppercase, first letter in uppercase, etc), your function will see the parameter `short` with a `bool` value of `True`. Otherwise as `False`.

注意：文档只列出了以上这些值，并没有给出完整的布尔真值列表（例如没有提到 `t`、`y`、`enabled` 等），所以这里只依据文档列出的内容作答。
