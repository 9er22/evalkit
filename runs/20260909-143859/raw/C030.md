# C030（adversarial）

**问** 在 FastAPI 里，response_model 应该作为路径操作函数的参数来声明，对吧？比如 def read_item(item, response_model=Item)。

**答**

不对。这份文档明确讲到，`response_model` 是**路径操作装饰器（decorator）方法的参数**，而不是路径操作函数的参数。

文档原文（response-model.md）中的说明：

> Notice that `response_model` is a parameter of the "decorator" method (`get`, `post`, etc). Not of your *path operation function*, like all the parameters and body.

也就是说，正确写法是把 `response_model` 传给 `@app.get()`、`@app.post()` 等装饰器，例如：

```python
@app.post("/items/", response_model=Item)
async def create_item(item: Item) -> Any:
    return item
```

而文档中给出的错误理解正是你写的那种形式——把 `response_model` 当作函数参数（如 `def read_item(item, response_model=Item)`）是不对的。

另外文档还提到，`response_model` 可以接收与 Pydantic 模型字段相同的类型，因此它也可以是 Pydantic 模型，或者是 Pydantic 模型的 `list`（如 `list[Item]`）。
