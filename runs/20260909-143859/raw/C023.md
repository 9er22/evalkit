# C023（edge）

**问** 文档推荐用 response_model_include / response_model_exclude 来隐藏字段吗？

**答**

不推荐。

文档在 `response_model_include` 和 `response_model_exclude` 一节里明确给出了提示（tip）：

> But it is still recommended to use the ideas above, using multiple classes, instead of these parameters.

也就是说，文档建议改用上面讲到的**多个类（multiple classes）**的方式（例如用输入模型 `UserIn` 和输出模型 `UserOut`，或通过类继承来过滤数据），而不是用 `response_model_include` / `response_model_exclude`。

文档给出的理由是：即使你用 `response_model_include` 或 `response_model_exclude` 省略了某些属性，你的应用 OpenAPI（以及文档）中生成的 JSON Schema 仍然是**完整模型**的 schema。文档还指出这一点同样适用于行为类似的 `response_model_by_alias`。

不过文档也说明，如果你只有一个 Pydantic 模型、只是想快速去掉输出中的某些数据，这两个参数可以当作一个快捷方式使用。
