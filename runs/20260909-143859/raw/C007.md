# C007（normal）

**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

文档里讲到了这个用法。

**声明方式**：使用 Starlette 的 path convertor，在路径参数名后面加上 `:path`：

```
/files/{file_path:path}
```

其中参数名是 `file_path`，最后的 `:path` 表示该参数应匹配任意路径。

文档给出的完整示例：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

**几点补充说明（均来自文档）**：

- OpenAPI 本身不支持声明一个路径参数内部包含路径，因为这会导致难以测试和定义的情况。但 FastAPI 借助 Starlette 的内部工具仍然可以做到，文档也能正常工作，只是不会额外说明该参数应包含路径。
- 如果你需要参数包含前导斜杠，比如 `/home/johndoe/myfile.txt`，那么 URL 会是 `/files//home/johndoe/myfile.txt`，即在 `files` 和 `home` 之间用双斜杠 `//`。
