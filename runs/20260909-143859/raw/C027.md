# C027（adversarial）

**问** 文档里提到的 response_model_exclude_password 参数怎么用？它是用来自动过滤掉敏感字段的吗？

**答**

这份文档没有讲到 `response_model_exclude_password` 这个参数。

文档中与"过滤敏感字段"相关的做法是：

1. **使用不同的输出模型**（推荐做法）：文档在 "Add an output model" 一节中，通过定义 `UserIn`（含 `password`）和 `UserOut`（不含 `password`）两个模型，并在装饰器上声明 `response_model=UserOut`，让 FastAPI 自动过滤掉未在输出模型中声明的字段（如密码）。

2. **`response_model_exclude` 参数**：文档提到可以用 `response_model_exclude` 传入一个 `set` 来排除指定属性，例如 `response_model_exclude={"tax"}`。理论上也可以用它排除 `password`，但文档并未给出这样的示例，且文档提示这种方式生成的 JSON Schema 仍是完整模型的。

文档中出现的其他相关参数只有：`response_model`、`response_model_exclude_unset`、`response_model_exclude_defaults`、`response_model_exclude_none`、`response_model_include`、`response_model_exclude`、`response_model_by_alias`。

所以，`response_model_exclude_password` 并不存在于这份文档中，我无法依据文档说明它的用法。
