# C022（edge）

**问** 如果我不想用 Pydantic 模型，还能声明请求体吗？

**答**

可以。文档在 Request Body 一节的最后「Without Pydantic」部分明确提到：

> If you don't want to use Pydantic models, you can also use **Body** parameters. See the docs for [Body - Multiple Parameters: Singular values in body](body-multiple-params.md#singular-values-in-body).

也就是说，除了 Pydantic 模型，你还可以使用 `Body` 参数来声明请求体。文档同时指向了另一篇文档（Body - Multiple Parameters 中的 "Singular values in body"）来了解具体用法。

不过需要注意，这份文档本身只给出了这个指引，并没有展开讲解 `Body` 参数的具体用法和示例。
