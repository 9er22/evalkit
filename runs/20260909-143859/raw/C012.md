# C012（normal）

**问** 怎么让一个查询参数变成必填？如果客户端不传，返回的错误长什么样？

**答**

## 怎么让查询参数变成必填

根据文档，**不要给这个参数声明任何默认值**，它就会变成必填的查询参数。

文档原文：

> But when you want to make a query parameter required, you can just not declare any default value

示例（来自 `docs_src/query_params/tutorial005_py310.py`）：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):
    item = {"item_id": item_id, "needy": needy}
    return item
```

这里 `needy` 是一个必填的 `str` 类型查询参数。

> 补充：文档还提到，如果只是想让它可选，就把默认值设为 `None`；如果声明了默认值，就不是必填的。

## 客户端不传时返回的错误

如果访问类似 `http://127.0.0.1:8000/items/foo-item` 而不带 `needy` 参数，会看到如下错误：

```JSON
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "query",
        "needy"
      ],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

带上参数（如 `?needy=sooooneedy`）就能正常工作：

```JSON
{
    "item_id": "foo-item",
    "needy": "sooooneedy"
}
```

## 混合使用

文档还说明，你可以同时定义必填参数、带默认值的参数和完全可选的参数：

```python
@app.get("/items/{item_id}")
async def read_user_item(
    item_id: str, needy: str, skip: int = 0, limit: int | None = None
):
    item = {"item_id": item_id, "needy": needy, "skip": skip, "limit": limit}
    return item
```

其中 `needy` 是必填的 `str`，`skip` 是有默认值 `0` 的 `int`，`limit` 是可选的 `int`。
