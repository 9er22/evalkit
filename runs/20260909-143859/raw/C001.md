# C001（normal）

**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档，使用与 Python 格式化字符串相同的语法来声明路径参数即可。文档中给出的完整代码如下：

```python
# docs_src/path_params/tutorial001_py310.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

依据文档说明：

- 路径参数 `item_id` 的值会作为参数 `item_id` 传递给函数。
- 因此运行该示例并访问 `http://127.0.0.1:8000/items/foo`，会得到响应：

```JSON
{"item_id":"foo"}
```

文档还提到，你也可以用标准的 Python 类型注解来声明路径参数的类型（例如 `item_id: int`），这样 FastAPI 会自动进行数据解析和校验。但就本问题而言，上面这段不带类型注解的代码即可满足需求。
