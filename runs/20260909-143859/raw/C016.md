# C016（normal）

**问** response_model 应该写在哪里？能写在路径操作函数的参数里吗？

**答**

`response_model` 不能写在路径操作函数的参数里，它是**路径操作装饰器**（`get`、`post`、`put`、`delete` 等）的参数。

依据文档中的说明：

> Notice that `response_model` is a parameter of the "decorator" method (`get`, `post`, etc). Not of your *path operation function*, like all the parameters and body.

也就是说，它和函数参数、请求体不同，是写在装饰器上的。文档给出的示例：

```python
@app.post("/items/", response_model=Item)
async def create_item(item: Item) -> Any:
    return item


@app.get("/items/", response_model=list[Item])
async def read_items() -> Any:
    return [
        {"name": "Portal Gun", "price": 42.0},
        {"name": "Plumbus", "price": 32.0},
    ]
```

另外，文档还提到 `response_model` 接收的类型和 Pydantic 模型字段一样，可以是 Pydantic 模型，也可以是 Pydantic 模型的 `list`（如 `List[Item]`）。
