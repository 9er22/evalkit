# C014（normal）

**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档：

**发送请求体应该用什么 HTTP 方法？**

文档（Request Body 章节）说明：要发送数据，应该使用以下方法之一：`POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`。

**如果用 GET 发送请求体会怎样？**

文档原文说明：

- 用 `GET` 请求发送请求体在规范中行为是未定义的（undefined behavior）。
- 不过 FastAPI 仍然支持它，仅用于非常复杂/极端的用例。
- 由于不推荐这样做，使用 Swagger UI 的交互式文档在使用 `GET` 时不会显示请求体的文档，而且中间的代理可能不支持它。
