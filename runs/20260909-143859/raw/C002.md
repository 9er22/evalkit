# C002（normal）

**问** 把 item_id 声明成 int 之后，访问 /items/3 时，函数里拿到的到底是字符串 "3" 还是数字 3？为什么会这样？

**答**

函数里拿到的是数字 `3`（Python 的 `int`），不是字符串 `"3"`。

依据文档 `path-params.md` 的 "Data conversion" 一节：

- 示例中把 `item_id` 声明为 `int`：

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

- 访问 `http://127.0.0.1:8000/items/3` 时，返回：

```JSON
{"item_id":3}
```

文档明确说明：

> Notice that the value your function received (and returned) is `3`, as a Python `int`, not a string `"3"`.

原因是：URL 里的值本身是字符串，但因为你用了 Python 类型声明（`int`），**FastAPI 会自动做请求 "parsing"**，把来自 HTTP 请求的字符串转换成对应的 Python 数据类型，所以函数收到的是 `int` 类型的 `3`。

另外，如果传入的不是合法整数（比如 `/items/foo` 或 `/items/4.2`），FastAPI 会基于同一类型声明做数据校验并返回错误，例如：

```JSON
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}
```
