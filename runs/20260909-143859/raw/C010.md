## 如何把查询参数声明为可选

根据文档，把查询参数的默认值设为 `None`，它就变成可选参数了。

### 代码示例

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

在这个例子中，函数参数 `q` 是可选的，默认值为 `None`。

### 判断依据

文档中明确说明：

> "The same way, you can declare optional query parameters, by setting their default to `None`"
> （同样地，你可以通过把默认值设为 `None` 来声明可选的查询参数。）

> "In this case, the function parameter `q` will be optional, and will be `None` by default."
> （在这种情况下，函数参数 `q` 将是可选的，默认值为 `None`。）

另外，文档在"Required query parameters"一节也补充了相关规则：

> "When you declare a default value for non-path parameters (for now, we have only seen query parameters), then it is not required. If you don't want to add a specific value but just make it optional, set the default as `None`."
> （当你为非路径参数声明了默认值时，它就不是必需的。如果你不想指定具体值而只想让它可选，就把默认值设为 `None`。）

### 补充说明

文档还提到，FastAPI 能智能地区分路径参数和查询参数：`item_id` 在路径中声明，所以是路径参数；而 `q` 不在路径中，所以被识别为查询参数。

> "Also notice that **FastAPI** is smart enough to notice that the path parameter `item_id` is a path parameter and `q` is not, so, it's a query parameter."

另外，在 `body.md` 中也有相关提示：判断参数是否必需，靠的是**是否有默认值**，而不是类型注解里的 `| None`：

> "The `str | None` is not used by FastAPI to determine that the value is not required, it will know it's not required because it has a default value of `= None`."

也就是说，真正让参数变为可选的是 `= None` 这个默认值，`str | None` 只是给编辑器提供更好的类型支持。
