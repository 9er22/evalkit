# C003（normal）

**问** 如果路径参数声明为 int，访问 /items/foo 会返回什么错误？请把完整的 JSON 错误结构写出来。

**答**

根据文档，如果路径参数 `item_id` 声明为 `int`，访问 `/items/foo` 会返回一个 HTTP 错误，完整的 JSON 结构如下：

```JSON
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": [
        "path",
        "item_id"
      ],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}
```

依据：文档 "Path Parameters" 章节的 "Data validation" 部分说明，因为路径参数 `item_id` 的值是 `"foo"`，它不是 `int`，所以会返回上述错误。文档还指出，如果传入 `float`（如 `/items/4.2`）而不是 `int`，也会出现同样的错误。
