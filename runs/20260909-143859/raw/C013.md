# C013（normal）

**问** 要接收一个 JSON 请求体，文档里怎么做？请给出完整代码，并说明哪些字段是必填。

**答**

## 如何接收 JSON 请求体

根据文档（`docs/en/docs/tutorial/body.md`），要接收请求体，需要用 Pydantic 的 `BaseModel` 定义一个数据模型，然后把它声明为路径操作函数的参数。

### 完整代码

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```

### 哪些字段是必填

文档明确说明：

> The same as when declaring query parameters, when a model attribute has a default value, it is not required. Otherwise, it is required. Use `None` to make it just optional.

即：**有默认值的字段不是必填，没有默认值的字段是必填**。

对照上面的 `Item` 模型：

| 字段 | 类型 | 是否必填 | 原因 |
|------|------|----------|------|
| `name` | `str` | **必填** | 没有默认值 |
| `description` | `str \| None` | 可选 | 默认值为 `None` |
| `price` | `float` | **必填** | 没有默认值 |
| `tax` | `float \| None` | 可选 | 默认值为 `None` |

所以下面这个 JSON 是合法的（省略了可选的 `description` 和 `tax`）：

```JSON
{
    "name": "Foo",
    "price": 45.2
}
```

### 补充说明

- 文档提到，发送请求体应使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`。用 `GET` 发送请求体在规范中行为未定义，虽然 FastAPI 支持，但不推荐。
- FastAPI 会自动读取请求体为 JSON、转换类型、校验数据，并把结果放到参数 `item` 中。
