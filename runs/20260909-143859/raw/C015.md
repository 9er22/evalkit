# C015（normal）

**问** 同一个路径操作里同时有请求体、路径参数和查询参数，FastAPI 怎么区分它们？

**答**

根据文档（`docs/en/docs/tutorial/body.md` 的 "Request body + path + query parameters" 一节），FastAPI 按以下规则识别函数参数：

- 如果参数名也声明在**路径**中，就作为**路径参数**。
- 如果参数是**单一类型**（如 `int`、`float`、`str`、`bool` 等），就解释为**查询参数**。
- 如果参数声明为 **Pydantic 模型**类型，就解释为请求**体**。

文档给出的示例：

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
```

其中 `item_id` 是路径参数，`item` 是请求体，`q` 是查询参数。

另外文档还特别说明：FastAPI 判断 `q` 不是必填，是因为它有默认值 `= None`，而不是因为类型注解 `str | None`；类型注解只是为了让编辑器提供更好的支持。
