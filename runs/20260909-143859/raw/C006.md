# C006（normal）

**问** 当路径参数是一个枚举成员时，怎么取出它真正的字符串值？

**答**

根据文档，当路径参数被声明为枚举类型时，函数收到的参数是一个**枚举成员**（enumeration member）。要取出它真正的字符串值，使用 `.value` 属性。

文档中的说明（来自 `path-params.md` 的 "Get the *enumeration value*" 一节）：

> You can get the actual value (a `str` in this case) using `model_name.value`, or in general, `your_enum_member.value`

也就是说，对于参数 `model_name`，用 `model_name.value` 取出其字符串值；一般形式为 `your_enum_member.value`。

文档还给出了一个具体例子，用 `ModelName.lenet.value` 来访问值 `"lenet"`：

> You could also access the value `"lenet"` with `ModelName.lenet.value`.

另外，文档提到枚举成员也可以直接返回，FastAPI 会在返回给客户端之前把它们转换成对应的值（这里是字符串）。
