**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档中的“Path Parameters”章节，声明路径参数的方式是在路径字符串中使用 `{参数名}`，并在函数中接收同名参数。对于访问 `/items/foo` 返回 `{"item_id": "foo"}`，最基础的写法（不声明类型）如下：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

依据是文档中的第一个示例（tutorial001_py310.py），它明确说明路径参数 `item_id` 的值会被传给函数，访问 `http://127.0.0.1:8000/items/foo` 时会返回 `{"item_id":"foo"}`。

如果你希望自动进行数据校验和类型转换，文档还建议使用 Python 类型注解，例如声明为 `int`：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}
```

但这样的代码访问 `/items/foo` 会因为 `foo` 不是整数而返回 422 验证错误，所以如果目标是让 `foo` 被原样接收并返回 `{"item_id": "foo"}`，应使用不带类型注解（或使用 `str`）的第一种写法。要启动这个应用，你需要将代码保存为文件（如 `main.py`），并使用 `uvicorn main:app --reload` 运行，文档本身并未包含启动代码，只给出了路由定义。
