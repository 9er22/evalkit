**问** response_model 应该写在哪里？能写在路径操作函数的参数里吗？

**答**

根据文档，`response_model` 是写在**路径操作装饰器**（path operation decorator）的参数里，而不是写在路径操作函数的参数里。

文档中的示例明确展示了这一点，例如：

```python
@app.post("/user/", response_model=UserOut)
async def create_user(user: UserIn) -> Any:
    return user
```

这里 `response_model=UserOut` 是作为 `@app.post("/user/")` 装饰器的参数传入的，而不是 `create_user` 函数的参数。

所以，`response_model` 不能写在路径操作函数的参数里，它必须作为路径操作装饰器的参数来使用。
