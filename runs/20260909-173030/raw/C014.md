**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档，发送请求体应该使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH` 方法。

如果用 `GET` 发送请求体，文档指出：
- 在规范中，用 `GET` 请求发送请求体具有未定义的行为（undefined behavior）。
- 尽管如此，FastAPI 仍然支持它，但仅用于非常复杂/极端的用例。
- 由于不鼓励这样做，Swagger UI 的交互式文档在使用 `GET` 时不会显示请求体的文档，而且中间的代理（proxies）可能不支持它。
