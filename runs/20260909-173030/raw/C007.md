**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

根据文档，你可以使用 Starlette 提供的 **path convertor** 来声明一个包含路径的路径参数。具体做法是在路径参数名后加上 `:path`，例如：

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

这样，`file_path` 参数就能匹配像 `home/johndoe/myfile.txt` 这样的完整路径。文档还提到，如果路径需要以斜杠开头（如 `/home/johndoe/myfile.txt`），URL 中需要写成 `/files//home/johndoe/myfile.txt`（即 `files` 和 `home` 之间用双斜杠）。
