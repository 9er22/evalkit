**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

根据文档，`response_model_exclude_unset=True` 是 *path operation decorator* 的一个参数，用于在响应中排除那些**未显式设置**的字段（即使用了默认值的字段），只返回实际被设置的值。

对于 id 为 `foo` 的 item，文档中的示例数据是：
```python
{"name": "Foo", "price": 50.2}
```

由于 `description`、`tax`、`tags` 这些字段在数据中没有被显式设置（它们会使用模型中的默认值），所以使用 `response_model_exclude_unset=True` 后，响应将**不包含**这些默认值字段，只返回实际设置的值：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```
