**问** 文档推荐用 response_model_include / response_model_exclude 来隐藏字段吗？

**答**

根据文档，**不推荐**用 `response_model_include` / `response_model_exclude` 来隐藏字段。

文档明确指出：

> But it is still recommended to use the ideas above, using multiple classes, instead of these parameters.

原因是：即使你使用 `response_model_include` 或 `response_model_exclude` 来省略某些属性，应用 OpenAPI（以及文档）中生成的 JSON Schema 仍然是完整模型的，不会反映这些省略。

文档建议的做法是使用多个 Pydantic 模型类（即"上面的思路"），而不是依赖这两个参数。
