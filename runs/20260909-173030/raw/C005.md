**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

根据文档，要让路径参数只接受预设的固定值，推荐使用标准的 Python `Enum` 类。

定义方式如下：

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

然后，在路径操作函数中，用这个枚举类作为路径参数的类型注解：

```python
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    ...
```
