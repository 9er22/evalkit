**问** 我的路径操作函数直接返回一个数据库对象（不是 Pydantic 类型），会发生什么？怎么解决？

**答**

根据文档，如果你的路径操作函数直接返回一个数据库对象（不是 Pydantic 类型），并且你在函数上做了返回类型注解，FastAPI 会尝试根据该类型注解创建一个 Pydantic response model，然后会失败。

文档中明确提到：

> But when you return some other arbitrary object that is not a valid Pydantic type (e.g. a database object) and you annotate it like that in the function, FastAPI will try to create a Pydantic response model from that type annotation, and will fail.

**解决办法**：文档建议在这种情况下，你可以设置 `response_model=None` 来禁用 response model 的生成。这样 FastAPI 会跳过 response model 的生成，你仍然可以保留返回类型注解以获得编辑器等工具的支持，但不会影响 FastAPI 应用。

```python
@app.get("/portal", response_model=None)
async def get_portal(teleport: bool = False) -> Response | dict:
    ...
```

文档说明：`This will make FastAPI skip the response model generation and that way you can have any return type annotations you need without it affecting your FastAPI application.`
