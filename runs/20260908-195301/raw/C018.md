# C018（normal）

**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

根据文档，`response_model_exclude_unset=True` 是 *path operation decorator* 的一个参数，作用是：**在响应中只包含实际被设置过的字段，不包含那些使用了默认值的字段**。

文档中的例子是：

```python
@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

其中 `items` 字典里 `foo` 对应的数据是：

```python
"foo": {"name": "Foo", "price": 50.2},
```

所以，用这个参数请求 id 为 `foo` 的 item，返回的响应（不包含默认值）会是：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```

也就是说，`description`、`tax`、`tags` 这些有默认值的字段不会出现在响应中，因为它们没有被实际设置。
