# C005（normal）

**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

根据文档，要让路径参数只接受几个预设的固定值，推荐使用标准的 Python `Enum` 类。

文档中给出的定义方式是：先导入 `Enum`，然后创建一个继承自 `str` 和 `Enum` 的子类。继承 `str` 是为了让 API 文档能识别出值必须是字符串类型。然后在类中定义固定值的类属性。

示例代码如下：

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

之后在路径操作中，将该 Enum 类作为路径参数的类型注解即可，例如：

```python
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    ...
```

这样，路径参数 `model_name` 就只能接受 `alexnet`、`resnet` 或 `lenet` 这三个预设值了。
