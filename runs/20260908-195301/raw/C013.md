# C013（normal）

**问** 要接收一个 JSON 请求体，文档里怎么做？请给出完整代码，并说明哪些字段是必填。

**答**

根据文档，要接收一个 JSON 请求体，你需要使用 Pydantic 的 `BaseModel` 来定义数据模型，然后在路径操作函数中将其声明为参数。

完整代码如下：

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```

关于字段是否必填，文档说明如下：

- **必填字段**：`name`（类型 `str`）和 `price`（类型 `float`）。因为它们没有默认值，所以是必填的。
- **可选字段**：`description`（类型 `str | None`，默认值为 `None`）和 `tax`（类型 `float | None`，默认值为 `None`）。因为它们有默认值，所以是可选的。

文档还提到，当模型属性有默认值时，它不是必填的；否则就是必填的。使用 `None` 作为默认值可以使其成为可选项。
