# C007（normal）

**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

根据文档，你可以使用 **path convertor** 来声明一个包含路径的路径参数。

具体来说，在路径参数名后面加上 `:path`，例如：

```
/files/{file_path:path}
```

这样，`file_path` 参数就可以匹配任何包含斜杠的路径。

文档中的示例代码如下：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

文档还提到，如果你的路径参数需要包含前导斜杠（例如 `/home/johndoe/myfile.txt`），那么 URL 中需要有两个斜杠，像这样：`/files//home/johndoe/myfile.txt`。
