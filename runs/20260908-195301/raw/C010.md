# C010（normal）

**问** 怎么把一个查询参数声明为可选？请给出代码，并说明判断依据是什么。

**答**

根据文档，要把一个查询参数声明为可选，可以**设置默认值为 `None`**。

文档中的示例代码如下：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

**判断依据**：文档在“Optional parameters”一节中明确说明：

> The same way, you can declare optional query parameters, by setting their default to `None`:
> 
> In this case, the function parameter `q` will be optional, and will be `None` by default.

另外，文档在“Required query parameters”一节中也强调，判断参数是否必需的关键在于**是否有默认值**，而不是类型注解：

> FastAPI will know that the value of `q` is not required because of the default value `= None`. The `str | None` is not used by FastAPI to determine that the value is not required, it will know it's not required because it has a default value of `= None`.

所以，核心判断依据是：**只要给查询参数设置了默认值（尤其是 `None`），它就是可选的**。
