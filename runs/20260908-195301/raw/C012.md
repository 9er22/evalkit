# C012（normal）

**问** 怎么让一个查询参数变成必填？如果客户端不传，返回的错误长什么样？

**答**

根据文档，要让一个查询参数变成必填，只需**不声明默认值**即可。例如：

```python
@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):
    item = {"item_id": item_id, "needy": needy}
    return item
```

这里 `needy` 就是一个必填的 `str` 类型查询参数。

如果客户端不传这个必填参数，比如访问 `http://127.0.0.1:8000/items/foo-item`，返回的错误如下：

```JSON
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "query",
        "needy"
      ],
      "msg": "Field required",
      "input": null
    }
  ]
}
```
