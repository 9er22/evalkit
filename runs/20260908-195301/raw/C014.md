# C014（normal）

**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档，发送请求体应该使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH` 方法。

如果用 `GET` 发送请求体，文档指出：
- 在规范中，使用 `GET` 请求发送请求体具有未定义的行为。
- 尽管如此，FastAPI 仍然支持它，但仅用于非常复杂/极端的使用场景。
- 由于不推荐这样做，交互式文档（Swagger UI）在使用 `GET` 时不会显示请求体的文档，并且中间的代理服务器可能不支持它。
