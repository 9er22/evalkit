# C001（normal）

**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档，你可以这样声明一个路径参数：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

依据文档中的说明：

> The value of the path parameter `item_id` will be passed to your function as the argument `item_id`.
> 
> So, if you run this example and go to [http://127.0.0.1:8000/items/foo](http://127.0.0.1:8000/items/foo), you will see a response of:
> 
> ```JSON
> {"item_id":"foo"}
> ```

这段代码中，路径参数 `item_id` 的值会被作为参数传递给函数，函数直接返回包含该值的字典。访问 `/items/foo` 时，`item_id` 的值就是 `"foo"`，因此会返回 `{"item_id": "foo"}`。
