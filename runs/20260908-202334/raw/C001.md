# C001（normal）

**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档，你可以使用 Python 的格式化字符串语法来声明路径参数。以下是完整可运行的代码：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

当你运行这个示例并访问 `http://127.0.0.1:8000/items/foo` 时，你会看到响应：

```JSON
{"item_id":"foo"}
```

依据是文档中的 "Path Parameters" 部分，其中说明了路径参数 `item_id` 的值会作为参数 `item_id` 传递给函数。
