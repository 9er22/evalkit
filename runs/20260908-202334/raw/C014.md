# C014（normal）

**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档，发送请求体应该使用 `POST`（最常见）、`PUT`、`DELETE` 或 `PATCH` 方法。

文档明确指出，使用 `GET` 请求发送请求体具有未定义的行为（undefined behavior）。虽然 FastAPI 支持这种用法（仅用于非常复杂/极端的情况），但这是不鼓励的。具体后果包括：

1. 交互式文档（Swagger UI）在使用 `GET` 时不会显示请求体的文档。
2. 中间的代理服务器可能不支持 `GET` 请求携带请求体。
