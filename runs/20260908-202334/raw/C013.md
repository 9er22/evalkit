# C013（normal）

**问** 要接收一个 JSON 请求体，文档里怎么做？请给出完整代码，并说明哪些字段是必填。

**答**

根据文档，要接收一个 JSON 请求体，你需要使用 Pydantic 的 `BaseModel` 来声明数据模型，然后在路径操作函数中将其声明为参数。

完整代码示例（来自文档 `docs/en/docs/tutorial/body.md`）：

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.post("/items/")
async def create_item(item: Item):
    return item
```

**必填字段说明：**

根据文档，当模型属性没有默认值时，该字段是必填的；有默认值时则不是必填的。使用 `None` 作为默认值可以使其成为可选字段。

在上述 `Item` 模型中：

- **必填字段**：`name`（类型 `str`）和 `price`（类型 `float`），因为它们没有默认值。
- **可选字段**：`description`（类型 `str | None`，默认值为 `None`）和 `tax`（类型 `float | None`，默认值为 `None`）。

因此，一个有效的请求体可以是：

```JSON
{
    "name": "Foo",
    "price": 45.2
}
```

而 `description` 和 `tax` 可以省略，因为它们有默认值 `None`。
