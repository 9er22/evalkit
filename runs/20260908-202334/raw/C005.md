# C005（normal）

**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

根据文档，要让路径参数只接受几个预设的固定值，推荐使用标准的 Python `Enum` 类。

文档中给出的定义方式是：先导入 `Enum`，然后创建一个继承自 `str` 和 `Enum` 的子类，再定义带有固定值的类属性。例如：

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

文档说明，继承自 `str` 是为了让 API 文档能够知道值必须是 `string` 类型并正确渲染。之后在路径操作中，用这个枚举类作为路径参数的类型注解即可，例如 `model_name: ModelName`。
