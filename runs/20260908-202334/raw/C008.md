# C008（normal）

**问** 如果 file_path 需要以斜杠开头（比如 /home/johndoe/myfile.txt），URL 应该怎么写？

**答**

根据文档，如果 `file_path` 需要以斜杠开头（比如 `/home/johndoe/myfile.txt`），URL 应该写成：

```
/files//home/johndoe/myfile.txt
```

即需要在 `files` 和 `home` 之间使用双斜杠（`//`）。

依据是文档中 "Path convertor" 一节的提示：

> You might need the parameter to contain `/home/johndoe/myfile.txt`, with a leading slash (`/`).
> In that case, the URL would be: `/files//home/johndoe/myfile.txt`, with a double slash (`//`) between `files` and `home`.
