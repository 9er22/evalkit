# C006（normal）

**问** 当路径参数是一个枚举成员时，怎么取出它真正的字符串值？

**答**

根据文档，当路径参数是一个枚举成员时，你可以使用 `your_enum_member.value` 来获取它真正的字符串值。

文档中的示例是：

```python
if model_name.value == "lenet":
    return {"model_name": model_name, "message": "LeCNN all the images"}
```

这里 `model_name` 是枚举成员，通过 `.value` 属性可以获取其对应的字符串值（例如 `"lenet"`）。文档还提到，你也可以用 `ModelName.lenet.value` 来直接访问特定枚举成员的值。
