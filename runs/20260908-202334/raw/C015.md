# C015（normal）

**问** 同一个路径操作里同时有请求体、路径参数和查询参数，FastAPI 怎么区分它们？

**答**

根据文档，FastAPI 通过函数参数的类型和声明方式来区分它们：

- 如果参数也声明在**路径**中，它会被用作**路径参数**。
- 如果参数是**单一类型**（如 `int`、`float`、`str`、`bool` 等），它会被解释为**查询参数**。
- 如果参数被声明为 **Pydantic 模型**的类型，它会被解释为**请求体**。

文档中的示例代码如下：

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
```

在这个例子中，`item_id` 是路径参数，`item` 是请求体（因为它是 Pydantic 模型 `Item`），`q` 是查询参数。FastAPI 会根据这些规则自动识别并从正确的位置获取数据。
