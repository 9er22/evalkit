**问** 要接收一个 JSON 请求体，文档里怎么做？请给出完整代码，并说明哪些字段是必填。

**答**

根据文档，接收 JSON 请求体的做法是：定义一个 **Pydantic 模型**（继承 `BaseModel`），然后把它作为函数参数的类型声明。文档说明，如果参数被声明为 **Pydantic model** 类型，它就会被解释为请求 **body**。

文档中给出的完整代码（片段 2/5，`docs_src/body/tutorial004_py310.py`）如下：

```python
from fastapi import FastAPI
from pydantic import BaseModel


class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None


app = FastAPI()


@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    result = {"item_id": item_id, **item.model_dump()}
    if q:
        result.update({"q": q})
    return result
```

关于哪些字段是必填：

- 在 `Item` 模型中，`name: str` 和 `price: float` 没有默认值，因此是必填字段。
- `description: str | None = None` 和 `tax: float | None = None` 有默认值 `None`，因此不是必填的。
- 函数参数方面：`item_id` 声明在路径中，是路径参数；`item` 是 Pydantic 模型，作为请求体；`q` 是单类型（`str`），会被解释为查询参数。文档特别说明，FastAPI 判断 `q` 不是必填，是因为它有默认值 `= None`，而不是因为 `str | None` 这个类型标注。

另外，文档（片段 3/5）说明，仅凭这样的类型声明，FastAPI 会：把请求体读取为 JSON、转换相应类型、校验数据（数据无效时返回清晰的错误，指出错误位置和内容）、把收到的数据放在参数 `item` 中，并为模型生成 JSON Schema，这些 schema 会成为生成的 OpenAPI schema 的一部分，供自动文档 UI 使用。

需要说明的是：文档没有明确写出“必填字段”这个词来逐一点名 `name` 和 `price`，上述必填判断是依据模型中这两个字段没有默认值这一事实得出的。
