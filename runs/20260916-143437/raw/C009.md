**问** 文档例子里的 skip 和 limit 两个查询参数，默认值分别是多少？如果只访问 /items/ 不传任何参数，会发生什么？

**答**

**默认值**：`skip=0`，`limit=10`。

依据【片段 1/5】："In the example above they have default values of `skip=0` and `limit=10`."（对应代码见【片段 5/5】：`async def read_item(skip: int = 0, limit: int = 10)`）

**只访问 `/items/` 不传任何参数**：效果等同于访问 `/items/?skip=0&limit=10`，即两个参数都取各自的默认值。

依据【片段 1/5】："So, going to the URL: `http://127.0.0.1:8000/items/` would be the same as going to: `http://127.0.0.1:8000/items/?skip=0&limit=10`"

（补充：文档还说明，如果只传 `?skip=20`，则函数中 `skip=20`、`limit=10`，因为 `limit` 用的是默认值。）
