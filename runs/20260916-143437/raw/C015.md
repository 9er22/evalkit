**问** 同一个路径操作里同时有请求体、路径参数和查询参数，FastAPI 怎么区分它们？

**答**

FastAPI 的区分规则在文档里有明确说明（片段 1/6，`docs/en/docs/tutorial/body.md` 的 "Request body + path + query parameters" 一节）：

- 如果参数同时声明在**路径**中，它会被当作**路径参数**（path parameter）。
- 如果参数是**单一类型**（singular type，如 `int`、`float`、`str`、`bool` 等），它会被解释为**查询参数**（query parameter）。
- 如果参数被声明为 **Pydantic 模型**的类型，它会被解释为请求**体**（request body）。

文档给出的示例：

```python
@app.put("/items/{item_id}")
async def update_item(item_id: int, item: Item, q: str | None = None):
    ...
```

其中 `item_id` 出现在路径 `/items/{item_id}` 中，所以是路径参数；`item` 是 Pydantic 模型 `Item`，所以是请求体；`q` 是单一类型 `str`，所以是查询参数。

另外文档还补充了一点（片段 1/6 的 note）：FastAPI 判断 `q` 不是必填，是因为它有默认值 `= None`，而不是因为写了 `str | None`；类型注解的作用是让编辑器提供更好的支持和错误检测。
