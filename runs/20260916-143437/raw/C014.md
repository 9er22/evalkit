**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档（片段 2/5，来源 docs/en/docs/tutorial/body.md）：

**发送请求体应该用的 HTTP 方法：**
文档说，要发送数据，应该使用以下方法之一：`POST`（最常见）、`PUT`、`DELETE` 或 `PATCH`。

**如果用 GET 发送请求体会怎样：**
- 在规范中，用 `GET` 请求发送 body 是未定义行为（undefined behavior）。
- 不过 FastAPI 支持这样做，仅用于非常复杂/极端的用例（very complex/extreme use cases）。
- 由于不推荐这样做，使用 `GET` 时 Swagger UI 的交互式文档不会显示 body 的文档，而且中间的代理可能不支持它。
