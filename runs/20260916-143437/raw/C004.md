**检索是否命中金标** 是

**问** 同时有 /users/me 和 /users/{user_id} 两个路径操作，声明顺序应该怎么排？写反了会发生什么？

**答**

应该把 `/users/me` 声明在 `/users/{user_id}` **之前**。

依据文档（片段 3/5，path-params.md 的 "Order matters"）：

- 因为 *path operations* 是按声明顺序依次求值的，所以必须先声明固定路径 `/users/me`，再声明带路径参数的 `/users/{user_id}`。
- 如果写反了，`/users/{user_id}` 会先匹配，它也会匹配到 `/users/me`，并"以为"自己收到了一个值为 `"me"` 的参数 `user_id`。

文档给出的正确顺序示例：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

另外，文档在同一节还提到：不能重复定义同一个路径操作（例如两个 `@app.get("/users")`），此时**第一个会始终生效**，因为它的路径先匹配上。
