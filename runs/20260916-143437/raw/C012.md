**问** 怎么让一个查询参数变成必填？如果客户端不传，返回的错误长什么样？

**答**

让查询参数变成必填的方法是：**不声明任何默认值**。

依据【片段 4/6 | 来源 docs/en/docs/tutorial/query-params.md】：

> But when you want to make a query parameter required, you can just not declare any default value

文档中的例子：

```python
@app.get("/items/{item_id}")
async def read_user_item(item_id: str, needy: str):
    item = {"item_id": item_id, "needy": needy}
    return item
```

这里 `needy` 就是一个必填的 `str` 类型查询参数。

如果客户端不传这个参数，会返回类似下面的错误（文档中访问 `http://127.0.0.1:8000/items/foo-item` 不带 `needy` 时的响应）：

```JSON
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "query",
        "needy"
      ],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

也就是说，错误信息里 `type` 为 `missing`，`loc` 指出是 `query` 中的 `needy`，`msg` 为 `Field required`。

另外，文档还提到可以混合使用：有的参数必填、有的有默认值、有的完全可选，例如：

```python
@app.get("/items/{item_id}")
async def read_user_item(
    item_id: str, needy: str, skip: int = 0, limit: int | None = None
):
    item = {"item_id": item_id, "needy": needy, "skip": skip, "limit": limit}
    return item
```

其中 `needy` 是必填的 `str`，`skip` 是有默认值 `0` 的 `int`，`limit` 是可选的 `int`。
