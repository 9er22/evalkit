**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档【片段 4/5 | 来源 docs/en/docs/tutorial/path-params.md】，可以用 Python 格式化字符串的语法来声明路径参数，完整代码如下：

```python
# docs_src/path_params/tutorial001_py310.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

文档说明：路径参数 `item_id` 的值会作为参数 `item_id` 传给函数。运行该示例并访问 `http://127.0.0.1:8000/items/foo`，会得到响应：

```JSON
{"item_id":"foo"}
```
