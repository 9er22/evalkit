**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

**作用**：`response_model_exclude_unset=True` 是 *path operation decorator* 的参数，设置后那些**没有被显式设置**的默认值不会包含在响应里，只返回实际设置过的值。（依据片段 2/6 和片段 5/6）

**请求 id 为 `foo` 的 item 时返回**：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```

依据片段 2/6：`items` 中 `"foo": {"name": "Foo", "price": 50.2}`，只设置了 `name` 和 `price`，所以 `description`、`tax`、`tags` 这些默认值不会出现在响应中。
