**问** 怎么把一个查询参数声明为可选？请给出代码，并说明判断依据是什么。

**答**

把查询参数声明为可选的方法是：给它设置默认值为 `None`。

依据【片段 1/6 | 来源 docs/en/docs/tutorial/query-params.md】中的说明和示例：

> The same way, you can declare optional query parameters, by setting their default to `None`

```python
# docs_src/query_params/tutorial002_py310.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str, q: str | None = None):
    if q:
        return {"item_id": item_id, "q": q}
    return {"item_id": item_id}
```

文档中明确说明：在这种情况下，函数参数 `q` 将是可选的，默认值为 `None`（"the function parameter `q` will be optional, and will be `None` by default"）。

另外，【片段 5/6 | 来源 docs/en/docs/tutorial/query-params.md】也补充了判断依据：当你为非路径参数（目前只涉及查询参数）声明了默认值时，它就不是必填的；如果你不想给它一个具体值、只想让它可选，就把默认值设为 `None`（"If you don't want to add a specific value but just make it optional, set the default as `None`"）。反之，不声明任何默认值就会使其成为必填查询参数。
