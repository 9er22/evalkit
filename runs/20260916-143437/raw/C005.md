**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

文档推荐用标准的 Python `Enum` 来预定义路径参数的合法取值。

做法是：导入 `Enum`，创建一个同时继承 `str` 和 `Enum` 的子类。继承 `str` 可以让 API 文档知道这些值必须是 `string` 类型，从而正确渲染。然后在类里用固定值定义类属性，这些就是可用的合法值。

文档给出的定义方式如下：

```python
from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

定义好之后，用这个枚举类作为路径参数的类型注解即可：

```python
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    ...
```

依据：片段 4/6（docs/en/docs/tutorial/path-params.md 的 "Predefined values" 一节）。另外片段 1/6 的提示也提到，`Enum` 可以像用于路径参数那样用于查询参数。
