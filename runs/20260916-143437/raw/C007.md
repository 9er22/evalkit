**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

文档说可以用 Starlette 的 **path convertor** 来声明这种路径参数。

具体做法是在路径里写成：

```
/files/{file_path:path}
```

其中参数名是 `file_path`，最后的 `:path` 告诉 FastAPI 这个参数应该匹配任意 *path*。

文档给出的示例：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

另外文档还提示：如果你需要参数本身包含前导斜杠，比如 `/home/johndoe/myfile.txt`，那么 URL 会变成 `/files//home/johndoe/myfile.txt`，也就是 `files` 和 `home` 之间是双斜杠（`//`）。

文档也说明 OpenAPI 本身不支持声明一个路径参数内部再包含路径，所以这种方式在文档里不会额外说明该参数应包含路径，但在 FastAPI 中仍然可用。
