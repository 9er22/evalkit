**问** 查询参数声明为 bool 类型时，URL 里写哪些值会被当成 True？请尽量列全。

**答**

根据文档（片段 6/6，`docs/en/docs/tutorial/query-params.md` 的 "Query parameter type conversion" 一节），当查询参数声明为 `bool` 类型时，以下写法都会被解析为 `True`：

- `?short=1`
- `?short=True`
- `?short=true`
- `?short=on`
- `?short=yes`
- 以及任何其他大小写变体（全大写、首字母大写等）

文档原文的说明是：

> or any other case variation (uppercase, first letter in uppercase, etc), your function will see the parameter `short` with a `bool` value of `True`. Otherwise as `False`.

也就是说，除了上述这些（及其大小写变体）之外的值都会被当作 `False`。

需要说明的是：文档只列出了 `1`、`True`、`true`、`on`、`yes` 这几个具体示例，并补充"任何大小写变体"都算 `True`，并没有给出一个完整的穷举清单。所以严格来说，文档没有讲到的其他可能取值（例如 `t`、`y`、`enabled` 等）是否算 `True`，这份文档没有讲到。
