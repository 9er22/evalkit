**问** 我需要一个路径参数，它本身包含斜杠，比如 /files/home/johndoe/myfile.txt。文档说该怎么声明？

**答**

文档说，可以用 Starlette 的 **path convertor** 来声明这种包含斜杠的路径参数，写法是在参数名后面加 `:path`：

```python
@app.get("/files/{file_path:path}")
async def read_file(file_path: str):
    return {"file_path": file_path}
```

依据（片段 4/4）：

- 文档指出 OpenAPI 本身不支持声明一个路径参数内部包含路径，但在 **FastAPI** 中仍可通过 Starlette 的内部工具实现。
- 使用 URL 形式 `/files/{file_path:path}`，其中参数名是 `file_path`，最后的 `:path` 表示该参数应匹配任意路径。
- 文档还提示：如果参数需要包含前导斜杠（如 `/home/johndoe/myfile.txt`），URL 会变成 `/files//home/johndoe/myfile.txt`，即 `files` 和 `home` 之间是双斜杠 `//`。
