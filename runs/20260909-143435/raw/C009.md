**问** 文档例子里的 skip 和 limit 两个查询参数，默认值分别是多少？如果只访问 /items/ 不传任何参数，会发生什么？

**答**

**默认值**：`skip=0`，`limit=10`。

依据片段 3（`docs/en/docs/tutorial/query-params.md` 的 "Defaults" 一节）：

> In the example above they have default values of `skip=0` and `limit=10`.

**只访问 `/items/` 不传任何参数时**：等同于访问 `http://127.0.0.1:8000/items/?skip=0&limit=10`，即两个参数都取默认值。

文档原文：

> So, going to the URL:
> ```
> http://127.0.0.1:8000/items/
> ```
> would be the same as going to:
> ```
> http://127.0.0.1:8000/items/?skip=0&limit=10
> ```

另外，文档还举了只传一个参数的情况：访问 `http://127.0.0.1:8000/items/?skip=20` 时，函数中 `skip=20`（因为 URL 里设置了），`limit=10`（因为那是默认值）。
