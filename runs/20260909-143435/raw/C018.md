**问** response_model_exclude_unset=True 是干什么的？用它请求 id 为 foo 的 item，会返回什么？

**答**

## `response_model_exclude_unset=True` 的作用

根据文档（片段 2/6），它的作用是：**让那些没有被显式设置、只是取了默认值的字段不出现在响应结果中**，只返回实际被设置过的值。

文档原文说明：

> You can set the *path operation decorator* parameter `response_model_exclude_unset=True` ... and those default values won't be included in the response, only the values actually set.

它常用于像 NoSQL 数据库这种有很多可选属性的模型，避免返回充满默认值的长 JSON。

## 请求 id 为 `foo` 的 item 会返回什么

文档中的 `items` 数据里，`foo` 是：

```python
"foo": {"name": "Foo", "price": 50.2},
```

它只显式设置了 `name` 和 `price`，其余字段（`description`、`tax`、`tags`）都取默认值。

所以请求 `foo` 时，响应（不包含默认值）为：

```JSON
{
    "name": "Foo",
    "price": 50.2
}
```

## 补充说明

文档还提到，如果数据里**显式设置**了某个字段（即使值恰好等于默认值），该字段仍会被包含在响应中。例如 id 为 `baz` 的 item，虽然 `description`、`tax`、`tags` 的值与默认值相同，但因为它们是显式设置的，所以会被包含进 JSON 响应。

另外，文档还提到可以配合使用 `response_model_exclude_defaults=True` 和 `response_model_exclude_none=True`。
