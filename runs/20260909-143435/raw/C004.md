**检索是否命中金标** 是

**问** 同时有 /users/me 和 /users/{user_id} 两个路径操作，声明顺序应该怎么排？写反了会发生什么？

**答**

应该把 `/users/me` 声明在 `/users/{user_id}` 之前。

依据文档（片段 3/5，path-params.md 的 "Order matters" 一节）：

- 因为 *path operations* 是按顺序求值的，所以必须确保 `/users/me` 的路径声明在 `/users/{user_id}` 之前。
- 如果写反了，`/users/{user_id}` 也会匹配到 `/users/me`，会"以为"自己收到了一个值为 `"me"` 的参数 `user_id`。

文档给出的正确写法：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/users/me")
async def read_user_me():
    return {"user_id": "the current user"}


@app.get("/users/{user_id}")
async def read_user(user_id: str):
    return {"user_id": user_id}
```

另外文档还提到，同样地你不能重复定义同一个路径操作（例如两个 `@app.get("/users")`），因为路径先匹配到的那个会一直被使用。
