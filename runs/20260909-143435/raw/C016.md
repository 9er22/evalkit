**问** response_model 应该写在哪里？能写在路径操作函数的参数里吗？

**答**

**不能写在路径操作函数的参数里。**

根据文档，`response_model` 是**路径操作装饰器（path operation decorator）的参数**，而不是函数参数。

文档中的示例都是这样写的：

```python
@app.post("/user/", response_model=UserOut)
async def create_user(user: UserIn) -> Any:
    return user
```

可以看到 `response_model=UserOut` 是写在 `@app.post(...)` 装饰器里的，函数本身的参数只有 `user: UserIn`。

文档在 Recap 中也明确说明：

> Use the *path operation decorator's* parameter `response_model` to define response models...

即使用**路径操作装饰器的参数** `response_model` 来定义响应模型。

同样地，`response_model_exclude_unset`、`response_model_include`、`response_model_exclude`、`response_model_by_alias`、`response_model=None` 这些也都是装饰器参数，例如：

```python
@app.get("/items/{item_id}", response_model=Item, response_model_exclude_unset=True)
async def read_item(item_id: str):
    return items[item_id]
```

所以结论是：`response_model` 写在路径操作装饰器里，不能写在函数参数里。
