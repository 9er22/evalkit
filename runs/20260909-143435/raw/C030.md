**问** 在 FastAPI 里，response_model 应该作为路径操作函数的参数来声明，对吧？比如 def read_item(item, response_model=Item)。

**答**

不对。这份文档明确讲到，`response_model` 是**路径操作装饰器**（`get`、`post` 等）的参数，而不是路径操作函数的参数。

依据片段 6/6 的说明：

> Notice that `response_model` is a parameter of the "decorator" method (`get`, `post`, etc). Not of your *path operation function*, like all the parameters and body.

文档中的正确写法是：

```python
@app.post("/items/", response_model=Item)
async def create_item(item: Item) -> Any:
    return item
```

也就是说，`response_model` 要写在 `@app.post(...)` 这类装饰器里，而不是写在 `def read_item(item, response_model=Item)` 的函数签名中。
