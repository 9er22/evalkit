**问** 发送请求体应该用什么 HTTP 方法？如果用 GET 发送请求体会怎样？

**答**

根据文档（片段 1/6）：

**发送请求体应该用的 HTTP 方法：**
应该使用以下方法之一：`POST`（最常用）、`PUT`、`DELETE` 或 `PATCH`。

**如果用 GET 发送请求体会怎样：**
- 在规范中，用 `GET` 请求发送请求体是**未定义行为（undefined behavior）**。
- 不过 FastAPI 仍然支持它，但**仅用于非常复杂/极端的用例**。
- 由于这种做法不被推荐，使用 `GET` 时 Swagger UI 的交互式文档**不会显示请求体的文档**，而且中间的代理可能不支持它。
