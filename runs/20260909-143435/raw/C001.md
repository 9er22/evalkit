**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

文档中没有直接给出"访问 `/items/foo` 返回 `{"item_id": "foo"}`"这个完整示例，但根据文档中路径参数的用法可以推导出写法。

依据【片段 6/6】中的示例，路径参数通过 `@app.get("/users/{user_id}")` 这种形式声明，函数参数名与花括号中的名字对应：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id: str):
    return {"item_id": item_id}
```

说明：
- 路径中的 `{item_id}` 是路径参数占位符，函数参数 `item_id: str` 与之对应（依据【片段 6/6】中 `/users/{user_id}` 的写法）。
- 访问 `/items/foo` 时，`item_id` 会被赋值为 `"foo"`，返回 `{"item_id": "foo"}`。

需要说明的是，文档中并没有出现 `/items/{item_id}` 直接返回 `{"item_id": item_id}` 的原始代码片段（【片段 3/6】和【片段 5/6】中的 `/items/{item_id}` 示例都额外包含了 `q`、`short` 或 `needy` 等参数），上述代码是依据文档中路径参数的通用声明方式组合得出的。
