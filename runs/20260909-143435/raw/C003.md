**检索是否命中金标** 是

**问** 如果路径参数声明为 int，访问 /items/foo 会返回什么错误？请把完整的 JSON 错误结构写出来。

**答**

会返回一个 HTTP 错误，完整的 JSON 结构如下（依据文档片段 4/6）：

```JSON
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": [
        "path",
        "item_id"
      ],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}
```

文档说明：因为路径参数 `item_id` 的值是 `"foo"`，它不是 `int`，所以校验失败。文档还提到，如果传入 `float`（例如 `/items/4.2`）也会出现同样的错误。
