**问** 想让一个路径参数只接受几个预设的固定值，文档推荐怎么做？请写出 Enum 类的定义方式。

**答**

文档推荐使用 Python 标准的 `Enum`（枚举）来预定义路径参数的合法取值。

具体做法是：导入 `Enum`，创建一个同时继承 `str` 和 `Enum` 的子类。继承 `str` 可以让 API 文档知道这些值必须是字符串类型，从而正确渲染。然后在类中定义固定值的类属性，这些就是可用的合法值。

文档中的 `Enum` 类定义方式如下：

```python
from enum import Enum

from fastapi import FastAPI


class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"
```

定义好之后，用这个枚举类作为路径参数的类型注解即可：

```python
@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    ...
```
