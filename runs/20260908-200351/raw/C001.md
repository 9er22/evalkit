# C001（normal）

**问** 根据文档，如何声明一个路径参数，让访问 /items/foo 时返回 {"item_id": "foo"}？请给出完整可运行的代码。

**答**

根据文档，使用与 Python 格式化字符串相同的语法来声明路径参数。文档中给出的完整代码如下：

```python
# docs_src/path_params/tutorial001_py310.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/items/{item_id}")
async def read_item(item_id):
    return {"item_id": item_id}
```

**依据说明：**

- 文档指出："You can declare path 'parameters' or 'variables' with the same syntax used by Python format strings"，即用 `{item_id}` 这样的语法声明路径参数。
- 路径参数 `item_id` 的值会作为参数 `item_id` 传递给函数："The value of the path parameter `item_id` will be passed to your function as the argument `item_id`."
- 文档明确说明，运行该示例并访问 `http://127.0.0.1:8000/items/foo` 时，会看到响应：

```JSON
{"item_id":"foo"}
```

这正是问题所要求的结果。
